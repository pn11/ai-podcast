# ai-podcast

読んだ論文を AI が要約・解説し、合成音声で読み上げて配信する個人ポッドキャスト。
GitHub Actions で生成し、GitHub Pages で RSS フィードを公開します。

- 設計: [docs/DESIGN.md](docs/DESIGN.md)
- フィード（予定）: https://pn11.github.io/ai-podcast/feed.xml

> このリポジトリはパブリックです。`queue/` や台本に個人的なメモ・個人情報を書かないでください。
> 配信内容は AI 生成であり、誤りを含む可能性があります。正確な内容は原論文を参照してください。
